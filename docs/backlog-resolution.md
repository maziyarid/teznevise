# Issue backlog resolution policy

The CodeAnt/Sonar issue backlog is considered complete only when every legitimate finding is:

1. fixed in a merged PR, or
2. explicitly documented as an exact duplicate/superseded finding and closed with a reference to the canonical issue/PR, or
3. verified as a false positive/not applicable and closed with the technical reason.

Generated findings are not to be closed merely because they are inconvenient or consolidated. Consolidation is allowed at implementation level, but each source issue must receive an explicit resolution.
